Borussia Merzig U12 – Live-Statistik v4

Neu gegenüber v3:
- Gespeicherte Spiele können jetzt einzeln gelöscht werden.
- Vor dem Löschen erscheint eine Sicherheitsabfrage.
- Das Löschen entfernt nur das gespeicherte Spiel, nicht den Kader und nicht das aktuell geöffnete Spiel.

Kernfunktionen:
- Kader einmalig anlegen
- Neues Spiel starten
- Pro Spieler per Fingertipp: Achtel, Punkte, Dreier, Rebounds, Assists, Turnovers, Fouls
- +3 zählt automatisch 3 Punkte und 1 Dreier
- Achtel werden pro Spieler und pro Achtel nur einmal gezählt
- Automatisches lokales Speichern nach jeder Aktion
- Rückgängig
- Spiel speichern / gespeicherte Spiele wieder öffnen / gespeicherte Spiele löschen
- CSV-Export
- Smartphone-/Tablet-Ansicht
- PWA mit Offline-Unterstützung über HTTPS

Die Daten werden im Browser des jeweiligen Geräts gespeichert.
